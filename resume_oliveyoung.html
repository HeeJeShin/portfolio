문제 해결 경험

Safari 브라우저 이슈 해결 및 팀 내 공유

현상

Safari에서 NICE 본인인증 팝업이 차단되고, 로그인 토큰이 유실되는 문제 발생

해결

  • NICE 인증을 팝업 → 페이지 리다이렉트 방식으로 전환
  • 쿠키 + localStorage 이중 저장으로 토큰 유실 방지
  • 회사에 Mac 장비 요청, iPhone으로 Safari 원격 디버깅 환경 구축

이후 조치

Safari는 외부 API 연동 시 공통적으로 문제가 발생 → 해결 과정과 체크리스트를 문서화해서 팀에 공유. 문서화는 AI 활용해서 빠르게 작성.
